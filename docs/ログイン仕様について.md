# ログイン関連画面

## モード
Create, // アカウント作成時
Edit, // アカウント編集時
Login // ログイン時#


## 仕様
### アカウント作成

#### 項目
・アカウント名（テキストボックス）
・パスワード（テキストボックス）
・パスワード再入力（テキストボックス）
・キャンセル（ボタン）
・登録（ボタン）

#### 処理
・キャンセルボタン
	アカウント一覧画面に戻る
・登録ボタン
	バリデーションを実施し、問題なければCredentialManagerに登録

### アカウント編集
#### 項目
・アカウント名（テキストボックス）
・現在のパスワード（テキストボックス、グレーアウト、マスキング表示）
・新しいパスワード（テキストボックス）
・新しいパスワード再入力（テキストボックス）
・キャンセル（ボタン）
・更新（ボタン）

#### 処理
・キャンセルボタン
	アカウント一覧画面に戻る
・更新ボタン
	新しいパスワードの一致確認
	入力したパスワードのバリデーションチェック
	バリデーションチェックで問題なければアカウント名に紐づくパスワードを更新


### ログイン
#### 項目
・アカウント名（テキストボックス）
・パスワード（テキストボックス）
・ログイン（ボタン）

#### 処理
アカウント、パスワードの一致を確認し、問題なければログイン成功
パスワードは完全一致

### バリデーション
・アカウント名重複禁止
・パスワード8文字以上64文字以下
・禁止文字
半角、全角スペース、<>, !, @ , #, ', ", `, &, ;, :、全角ひらがな
必須文字列
大文字、数字、英字
